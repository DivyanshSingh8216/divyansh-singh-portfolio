# Divyansh Singh — Personal Portfolio

Premium static React/Vite portfolio built from the saved portfolio specification and available project assets.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Included real assets

- InfraConn project imagery extracted from the uploaded project archive.
- Nagaland Tourism live-site screenshots supplied in the conversation.
- Selected implementation snippets taken from the uploaded InfraConn Laravel codebase.
- Portfolio master prompt retained as `MASTER_PROMPT.md`.

No `.env` or project secrets are included.
